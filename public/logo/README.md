# Hospital Logo Directory

This folder is dedicated for the official hospital logo.

### How to use your custom logo:
1. Place your hospital logo image in this folder (`/public/logo/`).
2. Supported formats:
   - `hospital-logo.svg` (Default high-resolution vector emblem)
   - `hospital-logo.png`
   - `logo.png`
3. The application will automatically display and frame your logo with high-tech red, black, and white neon framing across all application pages (Login Page, Navigation Bar, Executive Management Console, Ambulance Cockpit, and Doctor Station).
